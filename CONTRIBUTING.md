# Contributing

This source-release candidate is intended for private collaboration until publication rights are confirmed.

Please open an issue before substantial feature changes. Preserve the Stage 8 Increment 8 frozen baseline and make changes in feature branches. Keep provider adapters separate from the normalized model, add regression coverage for lifecycle policies, and do not commit real inventory or credentials.

Build locally with `zsh scripts/build_on_mac.zsh`. Automated checks are in `Tests/`. All merges require maintainer review and approval.
